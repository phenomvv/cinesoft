# CineSoft 🎬

CineSoft is a high-end, "Native-feel" mobile web application for tracking movies and TV shows. Built with a Bento Box grid architecture, it leverages Google's Gemini AI for personalized recommendations and TMDB for rich cinematic metadata.

## ✨ Features

- **AI-Powered Analysis**: Witty reviews and taste profiles generated by Gemini 3 Flash.
- **Bento Box UI**: Premium mobile-first design using CSS Grid and Framer Motion for fluid transitions.
- **Smart Search**: Semantic search capabilities allowing you to find movies by "vibe" (e.g., "Movies that feel like a warm hug").
- **Haptic Feedback**: Real-time tactile responses for interactions (on supported devices).
- **Comprehensive Library**: Manage your Watchlist, Favorites, and Watched History with ease.
- **Episode Tracking**: Detailed TV show management with season progress bars and episode-level tracking.
- **Pro Features**: Support for trailers, streaming provider data, and cast/crew details.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- A Google Gemini API Key (from [Google AI Studio](https://aistudio.google.com/))
- A TMDB API Key (optional, defaults to demo key)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/cinesoft.git
   cd cinesoft
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file in the root:
   ```env
   API_KEY=your_gemini_api_key_here
   TMDB_API_KEY=your_tmdb_api_key_here
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack

- **Framework**: React 19
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **AI**: @google/genai (Gemini 3 Flash & Pro)
- **Data**: TMDB API
- **Icons**: Lucide React

## 📱 Design Philosophy

CineSoft follows a **Mobile-First** and **Bento-Box** architecture. Every interaction is designed to feel fluid and native, utilizing blur effects, spring physics, and subtle scale transitions to provide a premium user experience.
